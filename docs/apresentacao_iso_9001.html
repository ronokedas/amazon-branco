Entradas e Saídas Controladas

Cada transição de etapa depende de dados validados pelo banco de dados MySQL e regras PHP em includes/sgq.php. Não existem laudos aprovados sem vínculo direto com uma ordem de vistoria executada e vistoriador qualificado.

Portões de Qualidade (Quality Gates)

O sistema aplica travas automáticas que impedem o avanço do fluxo quando ocorrem pendências regulatórias (ex: se houver retorno de A/S na etapa 4, o laudo é bloqueado e é disparada uma RNC).

5. Competência Técnica & Trava de Credenciais (ISO 7.2)
Barreira Tecnológica Antifalha Humana para Vistoriadores e Peritos Navais
Trava Bloqueante
O Risco Técnico Evitado

No setor naval, uma perícia realizada por profissional com credencial vencida na Capitania dos Portos ou registro suspenso no CREA/CFT é nula de pleno direito, gerando apreensão de embarcação e responsabilização civil/criminal.

Comportamento Sem o ERP: Falha humana no controle manual por planilhas resulta em agendamento indevido.
A Solução Implementada no Código

A função vistoriadorElegivelParaAgendamento() em includes/sgq.php intercepta qualquer tentativa de agendamento na API (modules/agendamentos/actions.php).

Comportamento Com o ERP: Resposta imediata HTTP 400 Bad Request impedindo salvar o agendamento no banco de dados.
Trecho da Regra de Negócio Compulsória (includes/sgq.php): 
if (empty($u['credencial_marinha_validade']) || strtotime($u['credencial_marinha_validade']) < strtotime('today')) {
    return ['elegivel' => false, 'motivo' => 'Credencial da Marinha vencida ou não informada'];
}
if (empty($u['registro_conselho_validade']) || strtotime($u['registro_conselho_validade']) < strtotime('today')) {
    return ['elegivel' => false, 'motivo' => 'Registro no Conselho de Classe (CREA/CFT) vencido'];
}

7. Saídas Não Conformes — Trava de Retorno A/S (ISO 8.7)
Tratamento de Pendências da Capitania dos Portos e Bloqueio de Certificados
Bloqueio CSN
O que é o Retorno A/S?

Ocorre quando a Capitania dos Portos / Autoridade Marítima aponta exigências técnicas impeditivas ou divergências estruturais que impedem a emissão definitiva do Certificado de Segurança da Navegação (CSN).

Disparo Automático no Sistema

Ao acionar encaminharRelatorioParaRetornoAS(), o ERP não depende de intervenção humana para abrir a Não Conformidade. O disparo é instantâneo e compulsório.

Sequência de Eventos do Bloqueio Automático
1. Bloqueio CSN

O laudo tem status alterado para RETORNO_AS e tem emissão travada no ERP.

2. Abertura RNC

Gera código oficial (ex: RNC-2026-0004) com severidade CRÍTICA.

3. Plano 5W2H

Gera plano de ação em sgq_planos_acao para nova vistoria in loco.

4. Alerta Gerencial

Dispara notificação para o Responsável Técnico e Gestor da Qualidade.

9. Não Conformidades & Ação Corretiva 5W2H (ISO 10.2)
Ciclo Fechado de Tratamento, Causa Raiz e Avaliação de Eficácia
Melhoria Contínua
O Ciclo de Vida da RNC no ERP
1. Registrada 2. Investigação (Causa Raiz) 3. Plano de Ação 5W2H 4. Implementada 5. Avaliada Eficaz (Fechada)
Metodologia 5W2H Estruturada no Banco de Dados (sgq_planos_acao)
Dimensão 5W2H Conteúdo Cadastrado no ERP
O quê (What) Ação de correção e ação preventiva contra reincidência.
Por quê (Why) Causa raiz diagnosticada (Diagrama de Ishikawa ou 5 Porquês).
Quem (Who) Responsável nomeado e qualificado pela execução técnica.
Onde (Where) Embarcação, projeto ou setor operacional afetado.
Quando (When) Prazo limite estipulado no cronograma.
Como (How) Procedimento técnico operacional adotado.
Quanto Custa (How Much) Custo financeiro orçado para mitigar o desvio.
Avaliação de Eficácia Verificação obrigatória após 30 dias para constatar se houve reincidência.
